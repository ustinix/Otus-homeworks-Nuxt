# E-Commerce Frontend Demo

Учебный проект интернет-магазина, демонстрирующий работу с современным стеком Vue/Nuxt.

## Project Overview

Проект реализует основные функции интернет-магазина:
- Просмотр каталога товаров
- Просмотр страниц товара
- Фильтрация по категориям
- Поиск по названию и описанию
- Адаптивный интерфейс

## 🛠 Technology Stack

- **Framework**: Nuxt 3 (SSR)
- **UI**: Vue 3 Composition API
- **State Management**: Pinia
- **UI Components**: Quasar
- **TypeScript**: Полная типизация
- **Deployment**: Netlify (только SSG)

## 🎯 Key Features

- ✅ Composition API с TypeScript
- ✅ Клиентская маршрутизация
- ✅ Работа с состоянием (Pinia)
- ✅ Адаптивный дизайн
- ✅ Поиск и фильтрация
- ✅ Оптимизация производительности
